# Stauffer Labs

Tools, libraries, and experiments in computer vision, AI, and software development.

- **Python** for libraries, tools, and backends
- **JavaScript/TypeScript** for frontends
- **Java** where needed

## Repositories

🔒 = private (visible to organization members only)

**Shared foundations**

| Repo | Description |
|---|---|
| [templates](https://github.com/stauffer-labs/templates) 🔒 | Copier templates for new projects: Python library, JS/TS library, full-stack app (FastAPI + React), Java library |
| [workflows](https://github.com/stauffer-labs/workflows) | Reusable GitHub Actions CI for Python, JavaScript/TypeScript, and Java |
| [py-common](https://github.com/stauffer-labs/py-common) 🔒 | Shared Python utilities |
| [js-common](https://github.com/stauffer-labs/js-common) 🔒 | Shared JavaScript/TypeScript utilities and UI components |
